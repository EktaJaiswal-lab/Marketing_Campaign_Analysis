# Marketing Campaign Analysis

Power BI dashboard for analyzing marketing campaign performance.

## Overview

This project explores campaign results to understand what drives conversions, engagement, and return on marketing spend. The dashboard is built in Microsoft Power BI and helps answer questions such as:

- Which campaigns perform best?
- How do different channels compare?
- Where should budget be focused next?

## Files

| File | Description |
|------|-------------|
| `Marketing_Campaign_Dashboard.xlsx` | Power BI / Excel workbook with the marketing campaign dashboard |

## How to open

1. Download or clone this repository.
2. Open `Marketing_Campaign_Dashboard.xlsx` in **Microsoft Excel** or import it into **Power BI Desktop**.
3. If prompted, enable editing / refresh data connections as needed.

- Microsoft Power BI / Excel
- Data visualization and dashboard design
